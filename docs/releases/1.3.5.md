# Mac 1.3.5

Status: signed local build. Public distribution is held while Apple developer agreements and notarization access are pending.

## Office visibility and live workers

- Native agent sessions and their running workers are discovered even when a per-process registry record is missing.
- Venue placement stays aligned with office floors as projects and teams change, so canopies no longer overlap office desks.
- Hide roofs now includes venue canopies and market awnings while keeping furniture and workers visible.
- Small generated offices use a single storey. Explicitly saved layouts and upper-floor choices remain available.
- Citizen movement handles tiny remaining distances without getting stuck in an update loop.

## Navigation and session details

- The Office minimap shows floors, workers and the current focus without adding another 3D renderer.
- Provider identity and the selected OpenCode model are shown as separate facts, including the variant when available.
- The local layout editor retains Preview, Save locally and Undo, along with per-room theme choices.
- Office, workstation and city views retain manual camera control, eight themes and the List fallback.
- A view-only browser Office uses the same live monitoring service without exposing provider controls.

## Downloads

The local Apple silicon build is Developer ID-signed. It is not yet notarized or publicly released. Public Apple silicon and Intel downloads must pass notarization before publication. Existing settings and local layouts are retained when updating.

The Windows-only v1.4.0 release remains available unchanged. This Mac release does not install or downgrade a Windows build.
